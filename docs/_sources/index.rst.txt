purpleair-matterbridge Documentation
====================================

The **purpleair-matterbridge** plugin bridges `PurpleAir <https://www2.purpleair.com/>`_
sensor data into the modern `Matter <https://csa-iot.org/all-solutions/matter/>`_ smart home
ecosystem via `Matterbridge <https://github.com/Luligu/matterbridge>`_. It allows you to
view real-time air quality, PM2.5 readings, temperature, and humidity directly inside
**Apple Home**, **Google Home**, and **Home Assistant** without relying on cloud bridges.

Key Features
------------

* **Native Matter Support:** Exposes PurpleAir readings as standard Matter air quality and environmental sensing clusters.
* **Smart Home Ecosystems:** Compatible with Apple Home, Google Home, Amazon Alexa, and Home Assistant.
* **Local Network First:** Operates locally via IPv6 and mDNS for low latency and high privacy.
* **Easy Installation:** Distributed as an npm package ready to integrate with Matterbridge.
